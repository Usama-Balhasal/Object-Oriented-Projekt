# Object-Oriented-Projekt

Ett enkelt 2D-CAD-program byggt i Java för projektet i kursen Objektorienterad design (DVG345) vid Högskolan i Gävle.

## Vad programmet gör
I programmet kan man rita och redigera olika geometriska figurer i 2D. Det går bland annat att:
* Rita linjer, cirklar, rektanglar, kvadrater och trianglar.
* Byta färg och tjocklek på linjerna.
* Markera, flytta, rotera och skala figurer.
* Gruppera figurer och dela upp grupper igen.
* Ångra och göra om ändringar (Undo/Redo).
* Spara och öppna ritningar som filer.

## Kom igång
1. Klona ner det här repot till din dator.
2. Öppna Eclipse och välj **File → Import → Existing Projects into Workspace**.
